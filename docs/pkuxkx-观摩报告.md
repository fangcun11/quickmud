# 北大侠客行（pkuxkx）观摩报告 —— 面向 quickmud 的借鉴与改进

> 观摩方式：网页客户端（mud.pkuxkx.net）实机观察登录流程与画面，结合官方 MUD 百科（pkuxkx.net/wiki）入门导读全文。
> 本报告面向 quickmud / 侠客行单机版的系统打磨，分四部分：视觉、操作、文案、系统设计，最后给出对比与改进建议。

---

## 一、视觉风格

实机观察（登录画面 → 注册提示）：

| 元素 | 做法 |
|---|---|
| 底色 | 纯黑（#000），无任何纹理/扫描线——可读性优先，不做"氛围" |
| 站名 | **青色（cyan）大字** `——== 北 大 侠 客 行 ==——`，全字间空一格，庄重醒目 |
| ASCII 艺术框 | 《侠客行》全诗以「黑底白字 + 蓝色点阵边框」的面板呈现，面板即"招牌" |
| 链接色分类 | 帐号说明/入门导读=**青色**、北侠主页=**白青**、QQ 群=**黄色**、警示文字=**红色**——颜色即语义 |
| 正文 | 白色为主，强调用黄/红，几乎不用其他颜色 |
| MOTD | 每次连线随机展示一段玩家写的江湖感言（`∷∷` 字符边框，署名 by xxx@pkuxkx）——**玩家创作的挽联式内容挂在门面上** |
| 状态数字 | 运行时长（"已执行六天二十一小时…"）、在线人数（"目前共有 524 位玩家在线上"）直接白字一行，不遮掩技术感 |

**要点**：北侠的"配色系统"只有 4 个语义色（青=标题/导航、白=正文、黄=重要、红=危险/警示），几十年不变。信息密度极高，一屏全是干货，装饰只有 ASCII 边框。

## 二、操作体验

- **终端即页面**：xterm 式滚动缓冲，输入行在底部；但同时也提供 `#command` 输入条（网页版）。
- **新手引导全程"提示驱动"**：未名谷新手村走到乱石阵，会听到"浑厚的声音"给一段**通用生存提示**（多看、多问、ask id about all）——把教学写进世界叙事，而不是 UI 弹窗。
- **命令有小写惯例**："你的所有输入都是小写"——降低输入门槛。
- **交互三板斧**：`look`（看得见的都能看，房间提示"你可以看看 xxx"）、`ask id about all`（不知道问什么就问 all）、`jobquery/jq`（不知道干什么就查任务）。**"不知道下一步干什么"永远有答案**。
- **防迷路三件套**：`localmaps(lm)` 本地地图、`walk`/`node` 自动行走（前辈们把路径沉淀成 node 库，输入 node 直接"嗖"地到达）、`help walk` 高级选项。**路径是社区资产**。
- **求助系统（大高手）**：`helpme ask 李莫愁` → 机器人自动回答攻略库答案，回答里带"提供者署名 [(zgbl提供)]"——**攻略被做成了游戏内服务**。
- **频道管理**：`tune channel` 逐个开关频道，官方引导新手关掉吵闹的频道。

## 三、文案特点

1. **书面语+武侠腔，但不做作**："行走江湖，多看多问"。
2. **诚实直白的系统话术**："目前共有 524 位玩家在线上""第一次连接乱码也是正常现象"——把丑话说在前面。
3. **善意的啰嗦**：PS、PS2、提示、提醒层层叠加；"新人不要错过的几件事：洗澡、里程碑……"。
4. **玩家署名文化**：MOTD 署名、攻略署名、node 路径全是"前辈们积累的"——文案在营造"江湖人情味"，这是北侠最核心的品牌资产。
5. **风险提示具体**："认真看任务说明，不注意的话也有可能变成真死""男性玩家请勿 kiss 李莫愁，后果自负"——用幽默代替免责声明。

## 四、系统设计（入门导读可见的部分）

| 系统 | 设计要点 |
|---|---|
| 账号/人物 | 英文名不可改、中文名可改（会随门派变化，如少林法号）、性别可改（有不可逆分支的幽默警告） |
| 新手村 = 教学关 | 未名谷全程引导任务，`jq` 查询下一步；出村时**一次性天赋洗点**（前四项总和 80，区间 10-30，灵性固定 30） |
| 天赋 | 六项：臂力/悟性/根骨/身法 + 福缘/容貌；影响拜师与武功上限，出村后不可改 |
| 门派 ×22 | 12 门派有专属新手任务；收徒规则各异（少林只收男、峨眉只收女、明教限经验 100 以下）；**判师惩罚**（师傅保留 20×次数 级武功不教） |
| 成长四资源 | 气血/精神（dazuo、tuna 提升）、内力（yun recover 回血、yun regenerate 回精神）、经验/潜能 |
| 任务矩阵 | 破阵>投名状>送信>慕容仆人，各有 reward/cd/危险度三维差异；**红豆答题**（答错无惩罚、次数上限随经验分段）；门派新手任务与日后武功挂钩（"错过了找补不回来"） |
| 经济 | 抄经任务（约 1 分钟 1 金）、捡垃圾卖当铺、**门派例银**（按 门忠>技能>经验 的增长率考核，按月发放，门派人数越多分越少）、钱庄联网通存通兑+存款上限 |
| 声望 | 禹王碑日活、徐霞客答题、军功兑换、爵位积分——多轨并行 |
| 导航 | 路引（新手限期道具）→ walk/node 路径库 → localmaps → 论坛机器人路径包 |
| 帮助 | help cmds、help xxx 直达 wiki、**大高手机器人**（helpme ask）、论坛/QQ 群/公益 id |

## 五、对比 quickmud（侠客行单机版）

| 维度 | 北侠 | 侠客行现状 | 差距/机会 |
|---|---|---|---|
| 配色语义 | 青/白/黄/红四色即语义 | 7 通道语义色（更细） | ✅ 已对齐，可再收紧 |
| 状态可见 | 顶状态卡+数字诚实 | prompt 条已有气血/内力/碎银/⚔ | 基本对齐 |

## 六、改进建议（按优先级）

1. **任务日志 / "下一步"引导（对标 jobquery）**：加 `任务` 面板已有雏形，补"建议下一步"：根据经验/等级给出 1-2 条可做之事（接任务、可学武功、可去地点）。这是"不知道干嘛"的解药，也是单机化的 jobquery。
2. **新手村教学关**：把现有三行欢迎语扩成一串引导任务（look→take→go→fight→eat 各来一次，完成即奖励），复用 quest 系统。
3. **前辈留言 / 江湖轶事（对标 MOTD）**：房间描述之外，随机展示"前辈留言"（预写的趣味文案池，可署名 NPC），把"人情味"做成内容资产；山神庙、客栈是天然挂点。
4. **helpme 式游戏内攻略**：`helpme ask 野狼` → 返回攻略条目（弱点、掉落、出没地）。把 help 文案升级为"问答体攻略库"，署名虚构前辈。
5. **例银式收益考核（数值化第一步）**：门派/师父 NPC 每月发例银，按"门忠/技能/经验 增长率"考核——把经济从"卖狼皮"升级为成长激励。
6. **node 路径的现代化**：已有点击行走；补一个 `去 <地名>` 远程路径（按预录路径自动走），对应 node/walk 的便利。
7. **配色收紧**：把 7 通道里低频通道（status/dialogue）收敛到北侠式四语义色 + 两个游戏专属色，减少视觉噪音。

## 七、实机游玩复盘（对 quickmud 最有价值的 10 个细节）

游玩记录全文见 `tools/play_record.txt`。挑对单机版最有借鉴意义的：

1. **hp 状态面板 = 一屏全知**：精神/气血/真气/内力/精力/战意/食物/饮水/潜能/经验
   十项数值 + 百分比 + 档位词（饥饿/饥渴/高昂）装进一个 ASCII 框。我们的 prompt 条
   只有 4 项——新手最需要的是"我现在全貌如何"。
2. **任务引导给到"命令级"**：jq 的输出就是下一步要敲的完整命令（ask yahuan about 葫芦），
   照抄即可。我们已有点击行走，补一个"你现在可以"面板即可对齐。
3. **物品状态诚实**：被人喝空的葫芦照样摆在未明谷地上（"葫芦已经被喝得一滴也不剩了"）——
   物品的 Usage 状态不隐藏，反而成为世界可信度的细节。
4. **饥饿/渴有身体反馈**：食物 0 →"你渴得眼冒金星，全身无力"——资源归零不是数字变红，
   而是写进身体感受。
5. **VOID 回收机制**：人物"没有环境"时被移到最後乐园（附企鹅可乐彩蛋文案），并自动送回
   新手谷。**任何异常状态都有叙事出口**，不让玩家卡死在纯系统报错里。
6. **断线体验**：重连有 y/n 踢人确认、offline_log 补看断线期间事件——多线路/掉线的
   用户沟通做得完整。
7. **环境行文案随时间轮换**：「高秋」的时辰播报不是固定一句，而是多段文学化文案随机取用
   （夜幕如急拉的黑幕/东方的天空渐渐的发白了……）。
8. **look 提示可交互对象**："你可以看看(look):river，path，〈air〉"——把隐藏交互点
   明示出来，探索有了抓手。
9. **世界的人味**：闲聊频道玩家挂机双簧、房间里的其他玩家 <断线二分钟> 标注——
   "活人感"是设计出来的（单机版可用 NPC 作息/留言系统模拟）。
10. **反挂机规则直说**：fullme 机制、机器人判定标准——规则透明比藏规则更让人服气。

## 附：实机连接实测记录（2026-09-06）

**环境与结论**
- `pkuxkx.com` DNS 解析异常（返回默认 nginx 页、证书不匹配）；可用入口：`mud.pkuxkx.net`（国内）/ `hk.pkuxkx.com`（海外）——两者最终解析到同一 IP。
- 官方网页客户端（mud.pkuxkx.net）连接约 1-2 分钟即被掐断（WebSocket 保活缺陷），输入条在连接稳定前禁用。
- **裸 TCP 直连 8081（UTF-8）/ 8080（GBK）稳定**：挂机 5 秒+无消息仍存活，颜色码完整。观摩/自动化请走 telnet 协议。

**登录阶段实测（对单机新手引导很有参考价值）**
1. 横幅 → 选编码（1 GBK / 2 UTF8 / 3 BIG5）→ 英文名提示。
2. 输入 `new` → **玩家须知**（未成年禁止，封禁至高考后）→ yes 确认。
3. 英文姓名（**只能 3-12 个小写字母**，数字/大写会被逐条打回）→ 密码 → 确认密码 → 性别(m/f) → 中文名……
4. **登录阶段有总时限**：超时后服务器把会话重置回默认编码横幅（之前所有"乱码+横幅"现象都是这个）。
5. 每一步的失败都有仪式感十足的 ASCII 送别诗（"今番良晤，豪兴不浅……咱们就此别过"）——连拒绝都是文案。
6. **新号按 IP 每日限流**："今天这个IP上已经创建太多的新账号了。"——反复尝试会烧掉当日配额，隔天重置。
7. 未完成的注册**不保存**：死在性别步骤的号，重新用同名注册即为新建。

**注册未能完成**：IP 日报额已耗尽，次日可再试（或用 Muder 网页客户端 http://mud.pkuxkx.net:4000 手动注册）。
